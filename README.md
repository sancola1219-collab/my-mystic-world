# 我的神奇世界

純前端 Canvas 遊戲合集，不用安裝。

- **線上直接玩（電腦、手機都可以）：https://sancola1219-collab.github.io/my-mystic-world/**
- 離線玩：下載後雙擊 `index.html`
- 手機請橫著拿；螢幕上會出現方向鍵、Z、X、跑、提示、音量按鈕，選單和塔防、小畫家都能直接用手指點
- 換裝置接著玩：主選單的「存檔搬家」可以把冒險進度匯出成檔案，再到另一台裝置匯入

打開後會先看到主選單，可以選三種玩法：

| 玩法 | 內容 |
|---|---|
| 幻紋大陸冒險 | 原創怪物收服 RPG：上千種幻靈、100 座道館、西遊記／忍者／星珠武道／彩虹幼稚園等番外篇、融合、坐騎 |
| 幻靈塔防 | 用十種屬性的幻靈當防禦塔，擋住一波波怪物；3 張地圖 × 普通／困難／地獄 |
| 幻靈小畫家 | 畫筆、彩虹筆、亮粉筆、形狀、文字、油漆桶、幻靈印章、左右對稱、特效濾鏡，還能用遊戲場景當畫板 |

## 操作

- 方向鍵移動、Z 確定、X 取消／選單、Shift 奔跑、M 音量、F 全螢幕
- 塔防和小畫家可以直接用滑鼠操作；所有選單也都能用滑鼠點

## 檔案

- `index.html`：入口
- `js/`：所有程式（依 `index.html` 裡的順序載入）
- `assets/posters/`：原創怪物的手繪原畫

存檔放在瀏覽器的 localStorage，不會上傳到任何地方。
